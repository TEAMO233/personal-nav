# 首页苹果风玻璃拟态像素级还原

## Goal

基于参考图 `/Users/teamo/Desktop/340519cc-2f1f-4f04-86ba-7421d15e492a.png`，把个人导航首页升级为苹果风 / macOS 风 / iCloud Dashboard 风格的深色玻璃拟态工作台，并尽量按截图的第一屏比例、层级、间距、色彩、圆角、毛玻璃质感和模块结构做像素级还原。

本次不是纯静态视觉稿还原。截图中现有项目缺失的业务能力需要补真实前后端功能和持久化数据，例如待办 / 日程、灵感便签、近期访问、首页概览等，不允许用 mock/fallback 假数据掩盖缺失能力。

用户价值：打开首页即可看到一个高级、干净、现代、可真实使用的个人导航工作台；视觉接近参考图，同时模块中的数据能被用户管理、持久化并按账号隔离。

## Confirmed Facts

### 参考图

- 图片尺寸为 `1672 x 941`，首要还原基准是桌面宽屏第一屏。
- 截图结构：
  - 顶部玻璃导航栏：左侧 logo +「个人导航」，右侧搜索、通知、主题、用户胶囊。
  - 主视觉欢迎区：居中欢迎语、副标题、宽胶囊搜索栏。
  - 8 个快捷入口卡片：工作台、开发文档、服务器、代码仓库、常用网站、AI 助手、日程待办、收藏夹。
  - 底部信息面板：最近访问、常用分类、今日概览、待办 / 日程、灵感便签。
- 视觉关键词：深蓝 / 午夜蓝背景、macOS 流线光效、半透明毛玻璃、细边框、大圆角、柔和蓝色高光、克制而不赛博朋克。

### 当前技术栈

- 前端：Vue 3.5 + TypeScript + Vite + Element Plus + Pinia + vue-router。
- 前端样式：原生 CSS + CSS 变量；没有 Sass/SCSS；不引入 Tailwind。
- 图标：当前项目使用自研 `AppIcon.vue` + Element Plus 图标环境；没有 `lucide-vue-next`。
- 后端：Spring Boot + JPA + Flyway + PostgreSQL + Redis；已有 Testcontainers 集成测试。
- 当前构建：前端 `npm run build` = `vue-tsc -b && vite build`；后端 Maven 测试走 `./mvnw test`。

### 当前首页

- `HomeView.vue` 已经有一轮玻璃化改造草稿：`DynamicBackground`、`HomeTopbar`、`HomeHero`、`CategoryNav`、`StatsPanel`、`GroupGrid`。
- 当前草稿偏“真实数据统计 + 分组快捷方式网格”，与本次像素级截图结构仍有明显差距。
- `SearchBar` 已有引擎下拉、搜索历史、Cmd/Ctrl+K 聚焦、右侧圆形按钮等能力，可继续改造视觉。
- `ShortcutCard` 当前显示图标 + 名称 + 域名，缺少截图需要的描述、色彩、固定 featured 展示等信息。

### 当前数据模型

- 已有真实资源：
  - `ShortcutGroup`：分组。
  - `Shortcut`：快捷方式，字段为 `groupId/name/url/iconAssetId/sortOrder`。
  - `SearchHistory`：搜索历史，不等于网站近期访问。
  - `SearchEngine`：搜索引擎。
- 缺失资源：
  - 待办 / 日程。
  - 灵感便签。
  - 网站最近访问记录。
  - 首页概览指标（专注度、待办数、日程数、系统状态等）对应的数据来源。
  - 快捷入口卡片所需的描述、色彩、featured 排序等展示字段。

### 代码规范

- 后端资源按“用户隔离实体 + Repository + Service + Controller + DTO + Flyway 迁移 + 集成测试”组织。
- 越权读取/修改用户资源时返回 404，不暴露资源存在性。
- 前端组件用 `<script setup lang="ts">`，顶部块注释说明组件职责；函数 JSDoc；函数内使用中文编号步骤注释。
- 组件显式 import；数据访问走 Pinia store -> api client -> 后端接口。
- 首页视觉使用纯 CSS 动态背景，不引入 Three.js；`backdrop-filter` 需要配 `-webkit-backdrop-filter`，并尊重 `prefers-reduced-motion`。

## Requirements

### 视觉还原

- 首页桌面第一屏以参考图为目标，优先还原：
  - 1672px 宽附近的整体比例、模块位置、间距和视觉密度。
  - 深蓝渐变背景和 macOS 弧形流线光效。
  - 顶栏 64px 左右、细分割线、玻璃质感。
  - 居中欢迎区、42px 级别标题、浅灰蓝副标题。
  - 760-820px 宽搜索栏、圆角胶囊、左搜索图标、右快捷键提示和圆形箭头按钮。
  - 8 个一行快捷入口玻璃卡片。
  - 底部 dashboard widget：最近访问、常用分类、今日概览、待办 / 日程、灵感便签。
- 桌面为主，兼容 1024/768/<768 响应式；移动端不要求与桌面像素一致，但不能破版或横向滚动。
- 不出现明显 Element Plus 默认后台风；主体样式以自定义 CSS / CSS 变量实现。
- 不用 emoji 作为结构图标；欢迎语挥手可按截图保留为文案符号，业务图标使用 SVG/AppIcon 或已有图标体系。

### 真实业务能力

- 待办 / 日程：
  - 后端新增用户隔离的待办/日程资源，支持列表、新建、更新、完成状态切换、删除。
  - 字段至少覆盖截图所需：标题、标签、计划时间、完成状态、排序/创建时间。
  - 首页展示最近 3 条待办/日程，并提供“添加待办”入口。
  - [已定] 只做首页内联管理，不做独立待办管理页；首页内支持添加、完成/取消完成、删除，更新可按实现复杂度做轻量编辑。
- 灵感便签：
  - 后端新增用户隔离的便签资源，支持列表、新建、更新、删除。
  - 字段至少覆盖截图所需：内容、是否置顶/星标、创建/更新时间。
  - 首页展示最新或置顶便签列表，连续新增不能覆盖前一条。
  - [已定] 只做首页内联管理，不做独立便签管理页；首页内支持新增、编辑、删除单条便签。
- 最近访问：
  - 后端新增网站访问记录，按用户隔离。
  - 点击快捷入口/快捷方式/首页书签时记录访问，作为真实访问日志保留。
  - 搜索历史仍保留原功能，不与最近访问混用。
- 首页书签：
  - [新增已定] 首页底部左侧不再以“最近访问”作为主面板，改为类似书签的可配置模式。
  - [新增已定] 顶部 8 个「工作台」到「收藏夹」继续作为首页快捷方式，后台维持现有快捷方式配置。
  - [新增已定] 首页书签配置入口放在 `/settings`，不放在 `/admin`。
  - 首页书签支持名称、链接、说明、图标、启用状态和排序等基础信息配置。
  - 最近访问记录能力保留为真实访问日志，点击首页书签 / 快捷入口时仍可记录，但不再作为首页底部左侧主展示模块。
- 通知：
  - [已定] 顶栏通知铃铛做真实通知能力，不做静态预留图标。
  - 后端新增用户隔离通知资源，支持列表、未读数、标记已读/全部已读。
  - 超时且未完成的待办 / 日程需要自动加入通知，通知内容应能关联回对应待办。
  - 首页顶栏显示未读 badge，点击铃铛展示玻璃下拉通知列表。
  - [已定] 待办完成后，对应超时通知自动标记为已解决，从未读和默认通知列表隐藏。
- 今日概览：
  - 首页概览必须由真实数据计算，不允许写死。
  - 待办事项数量和日程数量来自待办/日程资源。
  - 系统状态可来自本地 API 正常加载状态或后端健康/聚合接口；若没有独立健康接口，可在设计里明确“首页数据加载成功即正常”。
  - [已定] 截图中的“75% 今日专注度”改为真实“今日完成率”，算法为今天相关待办中已完成数量 / 今天相关待办总数；UI 可保留“今日完成率”或“今日专注度”风格文案，但数据含义必须可解释。
- 快捷入口：
  - 参考图的 8 个快捷入口必须是真实可点击资源或真实模块入口，不能只是纯展示卡片。
  - [已定] 扩展现有 `Shortcut` 作为首页精选入口，不新增独立首页入口表。
  - 新增展示字段至少包括：描述、强调色/图标 key、是否首页精选、首页精选排序。

### 现有功能零回归

- 搜索、引擎切换、搜索历史记录/删除/清空、Cmd/Ctrl+K 聚焦继续可用。
- 登录态、用户菜单、设置、管理后台入口、退出登录继续可用。
- 主题切换继续可用；如果首页主目标是深色，也要保证亮色不破版。
- 现有快捷方式/分组设置页不能被破坏。
