# 个人导航主页

## Goal

打造一个个人导航主页:页面中央是搜索框,搜索框头部显示当前搜索引擎图标(谷歌→谷歌图标、百度→百度图标),可下拉切换引擎;下方展示个人网站的快捷访问按钮。网站与图标均可由用户配置,配置持久化并随账号同步。

## Confirmed Facts (来自仓库证据)

- 全新项目,零业务代码;`.trellis/spec` 仍为模板,无既有约定可复用。
- 技术栈基线(由 `CLAUDE.md` 锁定):**后端 Java + 前端 Vue.js**。
- 可用基础设施:服务器具备 **MySQL、PostgreSQL、Redis**。
- 需求隐含"账号"概念:配置需"与账号同步"。

## Requirements (初稿,待访谈细化)

- R1 搜索框:中央展示,头部图标随所选引擎变化,支持下拉切换引擎。
- R2 快捷方式:下方网格展示个人网站快捷访问按钮(名称 + 图标 + 链接)。
- R3 可配置:搜索引擎列表、快捷方式(网站、图标)均可由用户增删改。
- R4 持久化与同步:配置存储于服务端,登录后随账号在不同设备/浏览器同步。

## Decisions (访谈结论)

- D1 用户模型:**多用户,受控开户**。关闭公开自助注册,改用「邀请码 + 管理员后台开户」二选一(详见 D9);数据按用户严格隔离(多租户)。
- D2 认证方式:**用户名 + 密码,不接入邮件服务**。无邮箱验证;无自助找回密码,密码重置由管理员后台处理。
- D3 数据架构:**PostgreSQL 单主库**(用户/引擎/快捷方式等关系数据)+ **Redis 辅助**(会话/登录令牌、热点配置缓存、注册登录限流)。MySQL 闲置不用,不做双关系库。
- D4 搜索引擎:**预置常用(Google/Baidu/Bing/DuckDuckGo,图标打包内置)+ 用户可自定义**(名称+搜索URL模板+图标,可排序/增删/设默认)。引擎配置按用户存库并同步。
- D5 图标/图片来源:**三合一**——填网址自动抓取 favicon(服务端抓取并缓存)作默认图标;支持上传自定义图片;支持填图片 URL。需要文件存储 + 服务端 favicon 抓取模块。
- D6 文件存储:**服务器本地磁盘 + 抽象存储层**(后端接口访问)。单机部署最简,抽象层保证日后可平滑切换 MinIO/OSS。
- D7 快捷方式组织:**分组 + 拖拽排序**(快捷方式归入分组,组内可拖拽、组间可拖拽、分组本身可排序)。
- D8 前端技术:**Vue 3 + Vite + TypeScript + Element Plus**(管理界面用组件库,首页搜索框/快捷方式自定义美化),支持暗/亮主题。
- D9 部署形态:**公网 + 强制 HTTPS**。关闭公开注册(见 D1),登录/开户接口用 Redis 限流防爆破;会话令牌走 Secure + HttpOnly Cookie,生产环境仅允许 HTTPS。需要「管理员」角色与最小管理后台(开户、重置密码、可选签发邀请码)。
- D10 多端适配:**响应式,首页移动友好 + 后台桌面优先**。首页(搜索框+快捷方式)响应式自适应,手机/平板可正常搜索与点击快捷方式;管理后台(增删改、拖拽排序)桌面优先,移动端保证可读可用,组内/组间拖拽在触摸端降级为「上移/下移/移动到分组」等按钮操作。
- D11 后端基线:**Spring Boot 3.x + Maven + JDK 21**。技术栈 Spring Security(认证/授权)+ Spring Data JPA(PostgreSQL)+ Spring Data Redis(会话/缓存/限流)+ Flyway(库迁移)。会话用服务端 session 存 Redis、Cookie 持 opaque sessionId(非无状态 JWT,便于即时注销与限流)。

## Acceptance Criteria

### 认证与账号(R4 / D1·D2·D9)
- [ ] 不存在公开注册入口;新用户仅能通过管理员后台开户或有效邀请码创建。
- [ ] 未登录访问首页或受保护接口被拦截并跳转登录;登录成功后令牌通过 HttpOnly+Secure Cookie 下发。
- [ ] 用户 A 登录后只能读写自己的引擎/分组/快捷方式,无法访问用户 B 的任何数据(多租户隔离)。
- [ ] 管理员可在后台为用户重置密码;无邮箱验证、无自助找回入口。
- [ ] 登录/开户接口超过阈值后被 Redis 限流;生产环境仅允许 HTTPS 访问。

### 搜索框与引擎(R1·R3 / D4)
- [ ] 首页中央展示搜索框,框头显示当前引擎图标;切到 Google 显示 Google 图标、切到 Baidu 显示百度图标。
- [ ] 输入关键词提交后,按所选引擎的 URL 模板跳转到正确的搜索结果页。
- [ ] 预置 Google/Baidu/Bing/DuckDuckGo(图标内置);用户可新增自定义引擎(名称+URL模板+图标)、排序、删除、设默认。

### 快捷方式与分组(R2·R3 / D5·D7)
- [ ] 首页按分组网格展示快捷方式(名称+图标+链接),点击在新标签打开目标网址。
- [ ] 用户可增删改分组与快捷方式;桌面端支持组内拖拽、组间拖拽、分组排序;移动端拖拽降级为按钮操作且排序结果持久化。
- [ ] 新增快捷方式时三种图标来源均可用并正确显示:填网址自动抓取 favicon、上传自定义图片、填图片 URL。

### 持久化与同步(R4 / D3·D6)
- [ ] 引擎/分组/快捷方式/偏好存储于 PostgreSQL 并按用户隔离;Redis 承担会话与热点配置缓存。
- [ ] 同一账号在不同设备/浏览器登录后看到的配置一致(随账号同步)。
- [ ] 上传图片与抓取的 favicon 经抽象存储层落到服务器本地磁盘,后端提供图片读取接口。

### 前端形态(D8·D10)
- [ ] 前端为 Vue 3 + Vite + TypeScript + Element Plus;支持暗/亮主题切换并记忆偏好。
- [ ] 首页在手机/平板上响应式自适应,可正常搜索与点击快捷方式;管理后台桌面优先,移动端可读可用。

## Out of Scope

- 邮件服务、邮箱验证、自助找回密码(D2:密码由管理员重置)。
- MySQL 关系库(D3:闲置不用,不做双关系库)。
- 第三方 OAuth / 社交登录(仅用户名+密码)。
- MinIO/OSS 等外部对象存储接入(D6:先本地磁盘,抽象层预留切换能力)。
- 浏览器书签导入/导出、多语言 i18n、PWA/离线、移动端原生 App。
- 团队/共享空间与协作(数据严格按个人隔离)。
